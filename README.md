# 棋牌游戏合集 (Board and Card Games Collection)

本项目整合了棋牌与相关游戏项目。

## 项目结构

- **[card_game/](file:///home/antigravity/suofengying981-lang/board-card-games/card_game)**: 包含斗地主、掼蛋、麻将、桥牌、扑克、军旗、跳棋、四川麻将等网页端/移动端（Capacitor）游戏及训练脚本。
- **[xiangqi/](file:///home/antigravity/suofengying981-lang/board-card-games/xiangqi)**: 中国象棋相关组件及插件项目。

## 快速开始

### 棋牌合集 (card_game)
- 直接在浏览器中打开 `card_game/index.html` 体验各款棋牌游戏大厅。
- 更多详细构建与运行说明，请参阅 [`card_game/README.md`](file:///home/antigravity/suofengying981-lang/board-card-games/card_game/README.md)。

### 象棋 (xiangqi)
